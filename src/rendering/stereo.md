# Stereo

## Stereo Mode

### Positional
Positional stereo is intended for use in stereo speaker setups rather than
headphone usage.

### Directional
Directional stereo might be more immersive for headphone listeners.

## Pan laws
The following pan laws are implemented:
- -3dB with sine taper
- -3dB with square root taper
- -6dB with linear taper
