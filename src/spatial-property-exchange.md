# Spatial property exchange (SPE)

The Spatial Property Exchange is an abstract protocol for sending and receiving
spatial properties across applications.

SPE enables spatially-aware audio processing. Audio effects using SPE can
create more immersive output as they are aware of where their input signals
are located within the scene. SPE also allows output signals to be given
spatial properties.

SPE-enabled applications can be designed so that the user only needs to think
of audio sources as one abstract idea instead of a pairing of audio data and
spatial data.
